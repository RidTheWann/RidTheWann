# RidTheWann

Software developer focused on systems programming, game-related tooling, and web applications.

Most of my repositories are personal projects: emulation and low-level work in C, C++ and Rust, plus web and business applications in TypeScript and JavaScript. I use them to learn how things work underneath, and to build tools I would actually use.

## Focus Areas

- Systems and low-level programming (emulation, operating systems, language tooling)
- Game-related tools, scripting and modding
- Web applications for business and everyday utilities
- Security-oriented software
- Machine learning experiments
